Sekilas tentang Abdan Rasya dan eksplorasi teknologi web.

Saya adalah seorang mahasiswa dengan minat mendalam pada pengembangan frontend web, sistem antarmuka terdistribusi, dan arsitektur komputasi awan (Cloud Platform as a Service).

Website ini dirancang secara khusus untuk memenuhi tugas praktikum Deployment Website Statis ke Cloudflare Workers pada mata kuliah pemrograman dan infrastruktur PaaS.

Prinsip Pengembangan:

  • Zero Bloat: Menggunakan Vanilla HTML, CSS, dan JavaScript tanpa ketergantungan framework berlebihan.
  • Edge Delivery: Menyajikan aset statis langsung melalui jaringan edge Cloudflare global untuk latensi minimal.
  • Git-Driven CI/CD: Setiap perubahan yang di-push ke branch main memicu deployment otomatis melalui Workers Builds.
